# 📊 Advanced Salary Analysis Dashboard (Excel)

An interactive Excel dashboard built using real-world 2023 data science job market data to analyse salary trends, skill demand, and compensation patterns across data-related roles.

The project leverages advanced Excel tools including Power Query, Power Pivot, DAX, Pivot Tables, and Pivot Charts to transform raw data into actionable insights.

---

## 🚀 Overview

The goal of this project was to build a business intelligence-style dashboard that allows users to explore salary distributions, identify in-demand skills, and compare compensation trends across different data-related careers.

Using interactive slicers, users can dynamically filter the dashboard by job title and country to generate tailored insights into the data science job market.

## 📂 Dataset

The dataset used for this project contains real-world data science job information from 2023 and includes:

- Job Title
- Salary Information
- Country
- Employment Type
- Skills Required
- Company Information
- Remote Work Status
- Hiring Trends

The dataset was cleaned and transformed using Power Query before being modelled in Power Pivot for analysis.

## 🏗️ Project Workflow

1. Imported and cleaned raw job market data using Power Query
2. Built a relational data model using Power Pivot
3. Created DAX measures for salary and skill calculations
4. Developed Pivot Tables and Pivot Charts
5. Designed an interactive dashboard using slicers
6. Generated actionable insights from the analysed data
