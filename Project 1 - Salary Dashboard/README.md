# 📊 Salary Dashboard (Excel)

An interactive Excel dashboard built using a dataset of 32,000+ data science job listings to analyse salary trends across roles, countries, employment types, and hiring platforms.

## 🚀 Overview

The goal of this project was to transform raw salary data into a user-friendly dashboard that enables quick exploration of compensation trends within the data industry.

Users can dynamically filter the dashboard by job title, country, and employment type to generate tailored salary insights.
